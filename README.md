# Bioinformatics Tools — student website

Public course website for the *Bioinformatics Tools* MSc course
(University of Neuchâtel, Vermeer lab). This repository holds only the
material shared with students; sources, solutions and assessments live in a
separate private repository.

## Build

```bash
quarto render      # build the site into docs/
quarto preview     # live preview while writing
```
